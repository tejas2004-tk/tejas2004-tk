### About

I'm a Computer Science student at D.Y. Patil School of Engineering and Management, Kolhapur. Most of what I build is **full-stack and shipped whole** — not a frontend demo with a fake API, but role-based auth, a real database schema, a REST layer, and a Docker Compose file that brings the whole thing up with one command.

Lately I've been working across two tracks: **production web apps** (React/Next.js + Node/Express + MySQL) and **applied ML** (document classification, AI-text detection, knowledge distillation for computer vision).

- 🔭 Currently building **ExamForge** — a full LMS with timed exams, anti-cheat, and auto-grading
